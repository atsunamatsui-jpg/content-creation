# Impact (impact.com)

- **URL:** https://impact.com
- **Category:** 4 — partnership / affiliate network
- **Priority: MEDIUM — different job, set up once.**

## How creators get work

Not campaign work. Impact is partnership-automation infrastructure: you join,
then apply to *individual brand programs* inside it. Earnings are commission on
conversions, though some brands also run paid placements through it.

Set-and-forget income on content nobody paid you for — worth doing precisely
because it doesn't compete for your application time.

## What it asks for

- Business/tax details — this is a payments platform, expect real onboarding
- Channel and audience information
- A separate application per brand program

## Working it

- Apply to brand programs that match content you *already* make. Affiliate income
  follows existing traffic; it doesn't create it.
- Check whether a program's terms allow affiliate links in the same post as
  sponsored content — some prohibit stacking.
- Watch for exclusivity clauses that would conflict with paid campaigns elsewhere.
- Affiliate content requires disclosure too, not just sponsored posts.
