# Per-platform notes

One file per platform. `scripts/parse_bookmarks.py --stubs` creates them from
your bookmark folder (and never overwrites a file you've already edited).

**The habit worth keeping:** the first time you fill in a platform's application
form, write down what it asked for — field by field, including character limits
and any required assets. Application #2 on that platform then takes five minutes
instead of forty, and you stop rediscovering the same requirements every time.

Worth capturing per platform:

- Exact fields the form asks for, and their character limits
- Whether it reads your analytics automatically or you type numbers in
- Whether campaigns are gifted, paid, or UGC-licensing
- Typical budget range you've actually seen
- Response time — how long before you should follow up
- Your running win rate (cross-check with `python3 scripts/track.py stats`)
